
# MQTT/TLS送受信テスト

Node-REDとCloudAMQPを使用して、MQTTメッセージの送受信を確認します。

MQTTXなどの追加ソフトウェアは必要ありません。

## 手順

1. Node-REDを起動します。
2. メニューの「読み込み」から `mqtt-test.json` をインポートします。
3. MQTTブローカーの接続設定を開きます。
4. 自分のCloudAMQPインスタンスのホスト名を設定します。
5. 「セキュリティ」タブでMQTTユーザー名とパスワードを入力します。
6. ポートが8883、TLSが有効、サーバー証明書の検証が有効であることを確認します。
7. Deployを実行します。
8. MQTTの送受信ノードがconnectedになったことを確認します。
9. 「撮影指示テスト」のinjectノードを実行します。
10. debug 2に受信メッセージが表示されれば成功です。

## 注意事項

- CloudAMQPの接続情報は自分の環境のものを使用してください。
- TLS設定内の「サーバー名」は通常、空欄のままで構いません。
- MQTTのユーザー名やパスワードをGitHubに登録しないでください。
- このテストでは、Spresenseへの通信はまだ確認していません。
